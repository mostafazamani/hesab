# دفتر حساب — حساب و کتاب شخصی

وب‌اپلیکیشن ساده و فارسی برای حساب‌وکتاب با اشخاص: ثبت **بدهکار** (پولی که به او داده‌اید) و **بستانکار** (پولی که از او گرفته‌اید)، نمایش جمع هر ستون، اختلاف و وضعیت طلب/بدهی، و خروجی اکسل از هر صورت‌حساب.

## امکانات

- ➕ افزودن چند طرف حساب (هر نفر یک صورت‌حساب جدا)
- 🧾 ثبت تراکنش با نوع (بدهکار/بستانکار)، مبلغ، **تاریخ شمسی** (تقویم تعاملی) و شرح
- 📊 جمع بدهکار، جمع بستانکار، اختلاف و جمله وضعیت («او به شما بدهکار است» یا «شما به او بدهکار هستید»)
- 📝 ویرایش و حذف طرف حساب‌ها و تراکنش‌ها، جستجو در تراکنش‌ها
- 📥 **خروجی اکسل** از یک صورت‌حساب یا همه صورت‌حساب‌ها (با شیت خلاصه، راست‌به‌چپ و قالب‌بندی رنگی)
- 💾 **پشتیبان‌گیری/بازیابی JSON** برای انتقال داده‌ها بین دستگاه‌ها یا مرورگرها
- 🖨️ چاپ صورت‌حساب (نمای مخصوص چاپ)
- 🌙 مبلغ‌ها با رقم فارسی و جداکننده هزارگان؛ فونت وزیرمتن
- 📱 ریسپانسیو (موبایل و دسکتاپ)

## ذخیره داده‌ها

کل داده‌ها در **localStorage مرورگر** ذخیره می‌شود — بدون سرور، بدون ارسال داده به بیرون. یعنی:

- داده‌های هر مرورگر/دستگاه جدا است؛ برای انتقال، از دکمه **پشتیبان‌گیری** فایل JSON بگیرید و در دستگاه مقصد **بازیابی** کنید.
- اگر داده‌های مرورگر پاک شود، اطلاعات حذف می‌شود؛ پس به‌طور دوره‌ای پشتیبان بگیرید.

## اجرای محلی

با [Bun](https://bun.sh):

```bash
bun install
bun run dev
```

سپس در مرورگر `http://localhost:3000` را باز کنید.

## انتشار روی GitHub Pages

این برنامه کاملاً سمت مرورگر اجرا می‌شود و به سرور نیاز ندارد؛ خروجی استاتیک آن روی GitHub Pages (یا هر هاست استاتیک دیگری مثل Netlify) قابل انتشار است.

1. کد را در یک مخزن (Repository) جدید در GitHub قرار دهید:

   ```bash
   git init
   git add .
   git commit -m "دفتر حساب"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO-NAME.git
   git push -u origin main
   ```

   (یا فایل‌ها را از طریق دکمه **uploading an existing file** در وب‌سایت گیت‌هاب آپلود کنید.)

2. در تنظیمات مخزن به **Settings → Pages** بروید و در بخش **Build and deployment** گزینه **Source** را روی **GitHub Actions** بگذارید.
3. کار **publish** در تب Actions به‌صورت خودکار اجرا می‌شود (روی هر push جدید هم دوباره اجرا می‌شود).
4. برنامه در این آدرس در دسترس خواهد بود:

   - اگر نام مخزن `USERNAME.github.io` باشد: `https://USERNAME.github.io`
   - در غیر این صورت: `https://USERNAME.github.io/REPO-NAME/`

   (مسیر پایه به‌صورت خودکار از نام مخزن محاسبه می‌شود — نیازی به تغییر تنظیمات نیست.)

### ساخت دستی خروجی استاتیک (اختیاری)

```bash
NEXT_STATIC_EXPORT=1 NEXT_PUBLIC_BASE_PATH=/REPO-NAME bun run build:static
```

خروجی در پوشه `out/` ساخته می‌شود و می‌توانید آن را روی هر هاست استاتیک آپلود کنید.

## تکنولوژی‌ها

- Next.js 16 (App Router) + TypeScript — کاملاً سمت کلاینت، بدون بک‌اند
- Tailwind CSS 4 + shadcn/ui
- localStorage به‌عنوان دیتابیس مرورگری
- ExcelJS برای ساخت فایل اکسل (نسخه مرورگر)
- jalaali-js برای تاریخ شمسی

## ساختار پوشه‌ها

```
src/
├── app/                    # صفحه اصلی اپلیکیشن، فونت وزیرمتن و استایل‌ها
├── components/ledger/      # کامپوننت‌های دفتر (فرم تراکنش، تقویم شمسی، جدول و...)
├── lib/
│   ├── store.ts            # لایه داده localStorage + پشتیبان‌گیری/بازیابی
│   ├── excel.ts            # ساخت ورک‌بوک اکسل (ExcelJS)
│   ├── export-client.ts    # دانلود فایل اکسل در مرورگر
│   ├── jalali.ts           # ابزارهای تاریخ شمسی
│   └── money.ts            # قالب‌بندی مبالغ
└── .github/workflows/      # اکشن انتشار خودکار روی GitHub Pages
```
