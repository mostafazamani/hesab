حساب‌کتاب — بستهٔ کامل انتشار روی GitHub Pages
================================================

محتویات این بسته (هر ۷ فایل لازم است، هیچ‌کدام را حذف نکنید):
  1. index.html      خود اپ حساب‌کتاب
  2. manifest.json   مشخصات نصب روی گوشی (PWA)
  3. sw.js           قابلیت اجرای کامل آفلاین
  4. icon-180.png    آیکون مخصوص آیفون
  5. icon-192.png    آیکون اندروید
  6. icon-512.png    آیکون اندروید با کیفیت بالا
  7. README.txt      همین راهنما (لازم نیست آپلود شود، ولی اشکالی ندارد)

مراحل انتشار روی گیت‌هاب:
  1. این فایل زیپ را در گوشی یا کامپیوتر خود باز (Extract) کنید.
  2. وارد مخزن (Repository) خود در GitHub شوید.
  3. روی Add file و بعد Upload files بزنید.
  4. هر ۷ فایل داخل زیپ را انتخاب و بکشید و رها کنید
     (فایل‌های قدیمی هم‌نام به‌طور خودکار جایگزین می‌شوند).
  5. پایین صفحه روی Commit changes بزنید.
  6. به Settings بروید، از منوی کنار Pages را انتخاب کنید:
        Source: Deploy from a branch
        Branch: main  |  Folder: / (root)
        و Save بزنید.
  7. ۱ تا ۲ دقیقه صبر کنید. آدرس سایت شما:
        https://USERNAME.github.io/REPO/
     (به‌جای USERNAME و REPO نام کاربری و نام مخزن خودتان)

نصب روی صفحهٔ اصلی گوشی:
  - آیفون: با Safari سایت را باز کنید، دکمهٔ Share (مربع با فلش)
    و بعد Add to Home Screen
  - اندروید: با Chrome سایت را باز کنید، منوی سه‌نقطه و بعد
    Add to Home screen یا Install app

اجرای آفلاین:
  - اولین باری که سایت را باز کنید، همهٔ فایل‌ها به‌طور خودکار
    ذخیره می‌شوند؛ از آن به بعد حتی بدون اینترنت هم اپ کامل باز می‌شود.
  - اگر بعداً نسخهٔ جدیدی از اپ به شما داده شد، فقط فایل‌های جدید را
    آپلود کنید و یک بار سایت را با اینترنت باز کنید تا به‌روزرسانی شود.

نکتهٔ مهم دربارهٔ اطلاعات:
  - داده‌های شما فقط در حافظهٔ مرورگر همان دستگاه ذخیره می‌شود.
  - هر از گاهی از داخل اپ دکمهٔ «پشتیبان‌گیری» را بزنید و فایل را
    جای امن نگه دارید؛ با «بازیابی» می‌توانید روی هر دستگاه دیگری
    اطلاعات را برگردانید.
